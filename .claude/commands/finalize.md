Finalize the current changes by running the following steps in order:

1. Run `make lint` to check and fix any lint errors
2. Run `make test` to run all tests (unit and LLM tests in parallel)
3. Run `make deploy` to deploy to the remote server
4. Commit all changes with a descriptive commit message
5. Push to git remote

If any step fails, fix the issue before proceeding to the next step.
